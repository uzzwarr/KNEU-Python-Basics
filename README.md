## 📚 Теми, що охоплюються

| Розділ | Теми |
|--------|------|
| **Practice #2** | Введення/виведення, арифметика, модуль `math` |
| **Practice #3** | Рядки: `split`, `upper`, `len`, `count`, форматування |
| **Practice #4** | Умовні оператори `if/elif/else`, цикли `for`/`while` |
| **Practice #5** | Функції, аргументи, рекурсія |
| **Practice #6** | Математичні ряди, умови зупинки за точністю |
| **Practice #7** | Списки: індексування, сортування, генератори списків |
| **Practice #8** | NumPy: `arange`, `linspace`, `random`, векторні операції |
| **Practice #9** | Matplotlib + Seaborn: лінійні графіки, гістограми, scatter, boxplot |
| **Lab #1** | Обчислення виразів, операції з рядками та цифрами числа |
| **Lab #2** | NumPy: матричні операції, зрізи, статистика |
| **Bonus Task #2** | Алгоритми пошуку у відсортованій матриці (5 реалізацій) |

## 🛠️ Технології

- **Python 3.x**
- **NumPy** — масиви та числові обчислення
- **Matplotlib** — побудова графіків
- **Seaborn** — статистична візуалізація

## ▶️ Запуск

Кожне завдання є самостійним файлом `main.py`. Для запуску:

```bash
cd Practice#8/Task#1
python main.py
```

Для завдань із графіками (Practice#9) результати автоматично зберігаються як `.png` у тій самій директорії.
